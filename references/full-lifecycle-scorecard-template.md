# Full-Lifecycle SOP Audit Scorecard Template

Use this table in EVERY SOP audit. Walk all 18 sections; assign a status per section
(GOOD / OK / PARTIAL / GAP / CONTRADICTION) and note the key finding ID if any.

| # | Lifecycle section | Status | Notes / Finding |
|---|---|---|---|
| 1 | Purpose & Scope | | intent + limits (screening-only? confirmatory caveat?) |
| 2 | Definitions / Abbreviations | | all body abbreviations defined? |
| 3 | Responsibility / Competency | | authorised person + training stated? |
| 4 | Sample Type | | matrix + container vs kit insert |
| 5 | Collection Timing | | window stated; "NA" contradicting text? |
| 6 | Handling / Transport / Stability | | temp/duration vs kit storage clause |
| 7 | Rejection Criteria | | matrix-appropriate (no serum-plasma boilerplate on DBS) |
| 8 | Test Procedure (step-wise) | | line-by-line vs kit; over-spec / wording drift |
| 9 | Calculation | | formula + units vs kit |
| 10 | IQC / EQC | | levels, rules, post-maint re-qual; "Control: NA" contradiction? |
| 11 | Calibration Frequency | | traceability beyond "kit opened" |
| 12 | Performance | | Precision/MU vs kit CV; Accuracy; Specificity |
| 13 | AMR / LOD / LOQ | | LOD ≤ LOQ ≤ AMR; vs kit sensitivity |
| 14 | Reference Interval | | sourced/locally validated, or fixed w/o basis? |
| 15 | Limitations / Potential Variation | | ALL kit cautions listed (transfusion, prem, LBW, sick, <48h)? |
| 16 | Safety | | generic GLP + reagent-specific hazards (TCA, azide)? |
| 17 | Clinical Interpretation | | mechanism text vs kit; substrate-name drift? |
| 18 | Reporting / TAT / Critical / Review | | TAT, urgent path, critical threshold, real review record? |
