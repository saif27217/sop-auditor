# SOP Structure Template — 21-Section Mandatory Framework

Use as a template when writing new SOPs or auditing existing ones against
ISO 15189:2022 §7.3.6 and NABL-112 requirements.

## Template

| # | Section | What it must contain | NABL/ISO basis |
|---|---|---|---|
| 1 | **Purpose & Scope** | Test intent + limits (screening-only? not confirmatory?) | ISO 15189:2022 7.3.6 |
| 2 | **Definitions / Abbreviations** | All abbreviations used in body defined (e.g. GALT/GALK/GALE/DBS/NBS) | ISO 15189:2022 7.3.6 |
| 3 | **Responsibility / Competency** | Who is authorised; any training prerequisite | ISO 15189:2022 6.2 |
| 4 | **Sample Type** | Matrix + container (e.g. Whatman 903 DBS); verify vs kit insert | NABL-112 § Pre-examination |
| 5 | **Collection Timing** | Window (e.g. Day 3–5 / 48–120 h); flag "NA" fields that contradict stated window | NABL-112 § Pre-examination |
| 6 | **Handling / Transport / Stability** | Temp, duration; verify vs kit storage clause | NABL-112 § Reagents |
| 7 | **Rejection Criteria** | MUST be matrix-appropriate. DBS SOP must NOT list "grossly haemolysed" (serum-plasma criteria) | NABL-112 § Pre-examination |
| 8 | **Test Procedure (step-wise)** | Volumes, incubation, read wavelength/mode; compare line-by-line vs kit insert | ISO 15189:2022 7.3.6 |
| 9 | **Calculation** | Formula vs kit; units consistent | ISO 15189:2022 7.3.6 |
| 10 | **IQC / EQC** | Levels, frequency, rules, post-maintenance/repair re-qualification, reference to internal QC SOP (e.g. MSP/18) | ISO 15189:2022 7.3.7 |
| 11 | **Calibration Frequency** | Beyond "when kit opened"; traceability to CRM/reference method (ISO 17511) | NABL-112 § Equipment |
| 12 | **Performance** | Precision (%CV) & MU vs kit's validated CV; Accuracy; Specificity (numeric or cross-ref); flag magnitudes ~2× kit as CAPA-level | ISO 15189:2022 7.3.1 |
| 13 | **AMR / LOD / LOQ** | Internal consistency (LOD ≤ LOQ ≤ AMR) and vs kit sensitivity | CLSI EP17 |
| 14 | **Reference Interval** | Sourced/locally validated, or fixed number with no basis (kit inserts often say "each lab must establish its own cut-off") | ISO 15189:2022 7.3.5 |
| 15 | **Limitations / Potential Sources of Variation** | List ALL kit-cited cautions (transfusion, premature, low-birth-weight, sick newborns, <48 h). An SOP that lists only one while kit lists five is PARTIAL | ISO 15189:2022 7.3.6 |
| 16 | **Safety** | Generic GLP PLUS reagent-specific hazards (e.g. TCA elution buffer is corrosive H315; sodium azide plumbing warning) | NABL-112 § Safety |
| 17 | **Clinical Interpretation** | Mechanism/deficiency text vs kit; watch substrate-name drift (e.g. "galactose-6 phosphate" vs kit's "galactose-1-phosphate") | ISO 15189:2022 7.3.6 |
| 18 | **Reporting / TAT / Critical Results / Review clause** | Turnaround time, urgent-report path, critical-value threshold, periodic-review record (not just footer) | ISO 15189:2022 7.3.4, 7.4.2 |
| 19 | **References** | Primary method reference (kit insert), internal SOP references (MSP/14, MSP/20), traceability citations | ISO 15189:2022 7.3.6 |
| 20 | **Appendices / Forms** | Any forms, logs, or work instructions referenced | ISO 15189:2022 7.3.6 |
| 21 | **Document Control** | Unique ID, approval before issue, revision status, review clause with frequency + owner, amendment log | ISO 15189:2022 8.3 |

## Key Rules

1. **No "NA" fields** — every field must have content or explicit "not applicable with reason"
2. **Matrix-appropriate rejection criteria** — DBS SOP must not copy serum-plasma boilerplate
3. **Cross-reference internal SOPs** — §4.19 References must cite MSP/14 (collection), MSP/20 (reporting), MSP/29 (risk)
4. **Numeric interference limits** — not just "haemolysis may interfere" but "Hb ≤200 g/L, bilirubin ≤40 mg/dL, TG ≤500 mg/dL"
5. **Review clause must be explicit** — "Reviewed & Issued by" footer does NOT count; need "This SOP shall be reviewed every 2 years or on change of method/reagent"

## Assessment Scale

| Rating | Meaning |
|---|---|
| **GOOD** | All 21 sections present with complete content |
| **OK** | All sections present, minor gaps (1–2 items PARTIAL) |
| **PARTIAL** | Missing 1–3 sections or major gaps in critical sections (7, 10, 11, 16) |
| **GAP** | Missing ≥4 sections or critical sections (7, 10, 11) incomplete |

## Worked Example: VDC BIO 166 v2 (Galactose-6-Phosphate Isomerase Deficiency)

| Section | Status | Notes |
|---|---|---|
| 1. Purpose & Scope | GOOD | Screening-only, not confirmatory stated |
| 2. Definitions | GOOD | GALT/GALK/GALE/DBS/NBS all defined |
| 3. Responsibility | GOOD | Competency requirements stated |
| 4. Sample Type | GOOD | Whatman 903 DBS specified |
| 5. Collection Timing | OK | "Day 3–5" stated, but "NA" field contradicts this elsewhere |
| 6. Handling / Stability | GOOD | Temp, duration vs kit storage clause verified |
| 7. Rejection Criteria | GAP | Lists "grossly haemolysed" (serum-plasma criteria irrelevant to DBS) |
| 8. Test Procedure | GOOD | Step-wise vs kit insert verified |
| 9. Calculation | GOOD | Formula vs kit, units consistent |
| 10. IQC / EQC | GOOD | MSP/18, RIQAS monthly cited |
| 11. Calibration | GOOD | Traceability to CRM stated |
| 12. Performance | GOOD | Precision, MU, Accuracy vs kit validated values |
| 13. AMR / LOD / LOQ | GOOD | Internal consistency verified |
| 14. Reference Interval | PARTIAL | Fixed range cited without derivation basis |
| 15. Limitations | PARTIAL | Only 1 of 5 kit-cited cautions listed |
| 16. Safety | GOOD | GLP + TCA H315, sodium azide warning included |
| 17. Clinical Interpretation | GOOD | Mechanism vs kit, substrate-name verified |
| 18. Reporting / TAT | GOOD | Turnaround time, critical values, review clause all present |
| 19. References | GOOD | Kit insert + MSP/14 + MSP/20 cited |
| 20. Appendices | GOOD | Forms listed |
| 21. Document Control | GOOD | Amendment log, version, review clause present |

**Overall: PARTIAL** — Rejection criteria matrix-inappropriate (GAP), Reference Interval derivation missing (PARTIAL), Limitations incomplete (PARTIAL).
